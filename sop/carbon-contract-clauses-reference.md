참조할 공인 표준(실제 원문 대조 없이 이름만 인용 — 사용 전 원문 확인 필수):

- The Chancery Lane Project (TCLP) — 기후 계약조항 오픈소스 라이브러리
- ICC 모델계약 부속 지속가능성 조항
- IETA 탄소거래 표준계약
- ISDA 배출권 파생 부속서

## 1. 배출데이터 제공 의무 (Data Provision Covenant)

- 공급자가 CBAM 방법론(현행 산정 이행규정)에 따른 사업장별 내재배출 데이터를
  분기/연 단위로, EU 집행위 Communication Template 형식으로 제공하는 조항.
- 최근 추세: EU 집행위 CBAM Operators Portal을 통해 제3국 사업장 운영자가
  검증된 배출데이터를 직접 업로드해 특정 EU 수입자와 공유 — 계약서에 포털
  업로드를 이행 방식으로 명시.
- 제공 기한(예: 분기 종료 후 30일), 검증보고서 사본 첨부 의무 포함.

## 2. 정확성 진술·보증 (Accuracy Warranty)

- "제공 데이터는 [산정 방법론 규정]에 따라 작성되었고, 중대한 오류가 없으며,
  인가 검증기관의 검증을 받았다" 수준의 보증.
- 실무상 공급자는 "합리적 주의(reasonable endeavours)" 수준으로 완화 협상,
  구매자는 절대적 보증 요구 — 중간 타협으로 "검증기관 의견서 기준 보증"이
  일반적이라고 알려짐.

## 3. 데이터 면책 (Disclaimer)

- 공급자 측 표준 문구: 기본값·산업평균·추정치 사용 부분은 "정보 제공 목적"
  으로 한정하고 보증 배제.
- 방법론·규정 변경(예: 전환기→확정기 계수 체계 변경)으로 인한 소급 재산정
  책임 배제 조항.
- 구매자 측 방어: 면책 범위를 "공급자가 통제할 수 없는 규정 변경"으로만 한정.

## 4. 기밀유지 (Confidentiality)

배출데이터는 공정·원단위·연료믹스 등 영업비밀을 노출하므로, 통상 다음을 포함:

1. 목적 제한 (CBAM 신고 목적으로만 사용)
2. 제3자 공개 범위를 관세당국·검증기관·집행위로 한정
3. 집계(aggregated) 형태 공개만 허용
4. 검증기관 경유 전달 옵션 (구매자가 원단위 원데이터를 직접 못 보게 하는 구조)

CBAM 레지스트리 제출 자체는 법정 의무이므로 기밀조항의 예외로 명시 필요.

## 5. 탄소 오차 손해배상 한도 (Liability Cap)

시장 표준이 아직 형성 중이며, 실무에서 관찰된다고 알려진 구조(일반 지식,
미검증):

| 요소 | 내용 |
|---|---|
| 직접손해 한정 | CBAM 인증서 추가 구매비용 + 과태료를 "직접손해"로 정의하고 간접·결과적 손해(영업손실 등) 배제 |
| 금액 상한 | 연간 계약금액의 일정 비율(예: 10~100%) 또는 해당 오류 물량분 CBAM 비용 실비 상한 |
| 기본값 차액 기준 | 배상액을 "실측값 부인 시 적용될 기본값과의 차액 × ETS 가격"으로 산식화 — 기본값이 실측보다 크게 높은 구조이므로 배상 산정의 자연스러운 기준이 됨 |
| 고의·중과실 예외 | 데이터 조작·고의 허위는 상한 적용 배제 |

## 6. 탄소비용 전가·가격조정 (Carbon Cost Pass-through)

- CBAM 인증서 비용(ETS 가격 연동)을 가격에 반영하는 조정 산식, 원산국
  탄소가격 지불분 공제 반영.
- ETS 가격 급변 대비 조정 주기·트리거 가격 명시.

## 7. 감사·검증 협조 (Audit Rights)

- 구매자 또는 인가 검증기관의 사업장 데이터 접근·현장 방문권.
- 규제당국 질의 시 협조 의무.
