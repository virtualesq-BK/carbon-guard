# 제안: CBAM Scope 1(직접배출) / Scope 2(간접배출) 배출계수

- 감지 계기: 사용자가 CBAM 보고용 Scope 1(연료·공정 배출계수)·Scope 2(전력 배출계수)
  수치 정리본을 제공하며 "확인해서 적용"을 요청함.
- 작성자: reg-watcher 역할 수행 (Claude, 세션 기준 2026-07-24)
- **반영 상태: 미반영 (요청드립니다 — 사람 검토 필요). `factors/`, `regulations/`에
  어떤 숫자도 아직 쓰지 않았습니다.**

## 0. 가장 중요한 정정 사항 — "기본값" 자체가 더 이상 유효하지 않음

사용자가 인용한 CBAM 이행규정(EU) 2023/1773 제4조 3항 내용은 정확합니다:
**2024년 8월 이후로는 기본값(default value) 사용이 원칙적으로 금지**되고,
실측 배출량(계산 기반 또는 측정 기반) 산정이 기본입니다.

여기에 더해 반드시 짚어야 할 시점 문제가 있습니다: **오늘은 2026-07-24입니다.**
CBAM 전환기간(transitional period)은 **2025년 12월 31일 종료**되었고, 2026년
1월 1일부터는 CBAM **확정(definitive) 단계**입니다. 즉:

- 사용자가 공유한 "EU 집행위 Default values 문서"(2023-12-22, 제가 직접 원문을
  가져와 확인함 — 아래 §1 참조)는 **전환기간 전용 기본값**이며, 이미 적용 시한이
  지난 자료입니다. 이 표의 수치를 지금 CBAM 보고서에 넣으면 오래된/부적용
  자료를 쓰는 셈이 됩니다.
- 2026년 이후 적용될 새 기본값 체계(수출국 평균 배출집약도 + 마크업 방식)는
  "2025년 implementing act로 결정 예정"이라고 명시되어 있었으나, 그 act가
  실제로 언제 채택되어 몇 번 규정으로 공표되었는지는 이번 조회로 확인하지
  못했습니다 — 별도 검증이 필요합니다.
- 확정 단계에서는 원칙적으로 **설치자(installation operator)의 실측 데이터**를
  사용해야 하므로, "표준 배출계수표"에 의존하는 접근 자체를 재검토할 필요가
  있습니다.

**결론: 사용자가 제공한 두 세트(Scope 1 Annex VIII 연료계수, Scope 2 한국 전력계수)
모두 지금 이 시점 기준으로 "확정 데이터"로 반영할 근거가 부족합니다.**

## 1. 검증된 내용 (제가 직접 원문을 가져와 확인함)

출처: `https://taxation-customs.ec.europa.eu/system/files/2023-12/Default%20values%20transitional%20period.pdf`
(European Commission, DG TAXUD, 2023-12-22, "Default values for the transitional
period of the CBAM between 1 October 2023 and 31 December 2025")

- 이 문서는 사용자가 언급한 Annex VIII **연료별** 계수(t CO2/TJ)가 아니라,
  **품목(CN 코드)별** 최종 배출계수(t CO2e/t 재화)를 담고 있습니다 — 철강·시멘트·
  비료·알루미늄·수소의 CN 코드별 직접/간접/총 배출계수 전체 표.
  (참고용으로만 남깁니다. §0에 따라 지금은 적용 불가.)
- **문서가 명시적으로 밝힌 사실**: 전력(간접배출) 기본값은 이 문서에 수치가
  "공개되어 있지 않다"고 명시합니다. IEA 2016–2020년 5개년 평균치를 국가별로
  담은 표는 **CBAM Transitional Registry(로그인 필요한 신고 시스템) 내부에서만
  제공**되며, 이 문서 자체에는 한국을 포함해 어떤 국가의 수치도 실려 있지
  않습니다. 즉 사용자가 인용한 "한국 값은 집행위 Default values 파일에서 확인"은
  이 PDF 기준으로는 **불가능**합니다 (등록 시스템 접근 권한 필요).

## 2. 검증하지 못한 내용

- **Annex VIII 연료별 산정계수(t CO2/TJ, 순발열량)**: 이행규정(EU) 2023/1773
  본문(EUR-Lex CELEX:32023R1773)과 운영자용 가이던스 문서(`CBAM Guidance_EU
  231121 for web_0.pdf`)를 모두 시도했으나, 이번 세션에서 사용 가능한 웹 조회
  도구가 EUR-Lex 원문과 해당 PDF의 표 부분을 읽어오지 못했습니다(빈 응답 /
  PDF 내부 압축 스트림 파싱 실패). 사용자가 제시한 수치(무연탄 98.3 t CO2/TJ
  등)는 IPCC 2006 기본값과 체계가 같다고 알려져 있지만, **Annex VIII 원문과
  1:1 대조는 하지 못했습니다.**
- **한국의 CBAM 전력 배출계수**: 위 §1에서 설명한 대로 공개 문서에 없고,
  등록 시스템 접근 권한이 없어 확인 불가.
- **2026년 이후(확정 단계) 기본값/방법론 개정 여부**: 확인하지 못함.

## 3. 권고 (사람 승인 필요)

1. **당장 `factors/`에 아무 숫자도 넣지 마십시오.** 지어낸 값이 아니라도,
   시효가 끝난 전환기간 기본값을 지금 보고서에 반영하면 오히려 오적용 리스크가
   더 큽니다.
2. Annex VIII 원문 대조는 EUR-Lex 계정이나 유료 법률 DB, 또는 CBAM 실무
   컨설턴트를 통해 사람이 직접 확인하는 것을 권합니다 — 이번 자동 조회로는
   신뢰 가능한 원문 텍스트를 확보하지 못했습니다.
3. 한국 전력 배출계수는 CBAM 신고자 계정(EORI 등록 후 CBAM Registry 접근)으로
   로그인해야 확인 가능한 것으로 보입니다. 담당 세관/관세사를 통해 확보하는
   경로를 권장합니다.
4. 2026년 확정 단계의 최신 방법론(기본값 폐지 후 실측 요건, 새 implementing act
   존재 여부)을 별도로 확인해야 합니다.
5. 위 내용이 사람에 의해 확인되면, 각 확정 수치를 `factors/` JSON에
   `source`(정확한 URL/조항)와 함께 채우고 `changelog.md`에 기록한 뒤 승인
   게이트 ①을 통과시켜 반영해 주십시오.
